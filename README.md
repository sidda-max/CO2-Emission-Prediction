# CO₂ Emission Prediction Using Machine Learning
**Live Demo:** https://sidda.pythonanywhere.com/

## Overview

This project predicts vehicle carbon dioxide (CO₂) emissions using Machine Learning. It uses a Linear Regression model trained on vehicle specifications and fuel consumption data.

The project includes a web application built with Flask that allows users to enter vehicle details and receive a predicted CO₂ emission value.

## Features

- Predicts vehicle CO₂ emissions from user-provided inputs.
- Uses a Linear Regression model from Scikit-learn.
- Provides a web interface using Flask, HTML, and CSS.
- Accepts vehicle engine, cylinder, fuel consumption, fuel type, transmission, make type, and vehicle class details.
- Evaluates the model using Mean Absolute Error (MAE) and the R² score.

## How It Works

1. The vehicle dataset is loaded using Pandas.
2. Vehicle specifications and fuel consumption values are used as input features.
3. The CO₂ emission column is used as the prediction target.
4. The dataset is split into training and testing sets.
5. A Linear Regression model is trained using the training data.
6. Model performance is evaluated using MAE and R².
7. The Flask web application collects vehicle details from the user.
8. The trained model predicts the vehicle's CO₂ emissions and displays the result.

## Model Evaluation

The model is evaluated using:

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted emissions.
- **R² Score:** Measures how well the model explains the variation in the target values.

The actual evaluation results are printed in the terminal when the application starts.
